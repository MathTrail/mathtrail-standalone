# Olympiad maths that never runs out

An endless stream of checked olympiad maths tasks for grades 1–6, in any
language, with a diagnosis of the mistake and a memory of how the child is
progressing.

MathTrail is an app for the chat you already use. A parent or a tutor connects
it to their own Claude or ChatGPT, and the child solves tasks there: the chat's
model writes the task, and MathTrail decides whether it is good enough to reach
the child.

It is neither a homework solver nor a drill of the school syllabus.

[The source code is on GitHub](https://github.com/MathTrail/mathtrail-standalone)
