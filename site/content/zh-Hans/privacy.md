# 隐私政策

最后更新：2026年10月10日。

MathTrail 是一个免费的开源项目，由 ALT EdTech 开发和运营。关于本政策或您孩子数据的问题，请发送至 [altedtech.info@gmail.com](mailto:altedtech.info@gmail.com)。如何连接 MathTrail，以及发现异常时该怎么办，请见[帮助页面](../help/)。

## 简要说明

- **我们什么都不存储**。服务没有数据库，也不保存任何文件。在两次请求之间，它什么都不记得。
- **您孩子的档案存放在您自己的 Google 云端硬盘中**，是一个您随时可以打开、复制或删除的文件。
- **只用化名，绝不用真实姓名**。没有出生日期，没有学校，没有照片。
- **我们统计孩子的人数，但不知道每个孩子是谁**。日志中的一行用一个代码指代孩子，这个代码每月更换，也无法追溯到任何人；保存两个月以上的都是总数。
- **什么都不出售，什么都不用来训练模型**。
- **删除文件就删除了档案**。任何地方都没有第二份副本。

## MathTrail 是什么

MathTrail 是一个由您添加到自己的 Claude 或 ChatGPT 中的应用。它为您的孩子选择专题和难度，请聊天自己的模型写一道题，用程序检查这道题，把题展示出来，记录答案并讲解错误。

MathTrail 不运行任何自己的语言模型。写题的模型就是您已经在用的那个聊天里的模型；您与该聊天服务提供商之间的关系，受其条款和隐私政策约束，而不受本政策约束。

## 谁来登录

只有成年人，也就是家长或老师。孩子没有自己的账号，也不用自己登录。各聊天平台有各自的年龄规定：Claude 面向成年人，ChatGPT 要求青少年取得家长同意。MathTrail 并不面向独自使用聊天的孩子。

## 孩子

MathTrail 的题目面向1～6年级的孩子，年龄大约在六到十二岁之间。按设计，它的用法是成年人在聊天中打字，孩子在一旁点卡片上的选项来作答。孩子没有账号。档案中保存的是成年人以化名提供的关于孩子的信息，以及孩子的作答，存放在成年人自己的文件里；服务的日志会保留这些作答中的哪些内容、保留多久，见下文。

## 存储什么，存在哪里

### 在您的 Google 云端硬盘中

档案是单独一个 JSON 文件 `mathtrail-profile.json`，位于您自己云端硬盘中名为 `MathTrail` 的文件夹里。您可以像对待其他任何文件一样打开、阅读、复制、移动或删除它，云端硬盘的回收站和版本记录也都归您所有。

其中包含：

- 孩子的**化名**、年级、兴趣爱好，以及您要求避开的内容；
- 孩子的一个标识符，以便将来把档案迁移到新的版本；
- 界面语言（如果您选择过）；
- 为课程选定的专题（如果您或孩子选择过）；
- 您居住的国家，在美国还有您所在的州（如果您选择提供）：它们只用于统计每个国家有多少家庭，您也可以不提供；
- 哪些专题已掌握、决定难度的评分数值，以及以往作答的摘要：每个专题最近一次出题的时间、尝试和答对的次数，以及出现过哪些陷阱；
- 最近每次作答之前的评分，以及最近七个有作答的日子里每天开始时的评分，这样进度就能显示自上一题以来和近一周的变化；
- 今天已接受题目的计数器（每天的上限就是靠它执行的），以及孩子作答所用设备的时钟比 UTC 快多少或慢多少：卡片会随每次作答一起发送这个值，这样一天就会在您当地的午夜结束；
- 当前的题目，其答案经过加密，在孩子作答之前无法从文件中读出；
- 下一道题：孩子做当前这道题时，聊天会提前把它写好，其答案以同样的方式加密，一直保存到有人请求它为止。

档案中不包含孩子的姓名、出生日期、学校、住址、照片，或其他任何能识别孩子身份的信息。**化名是其中涉及的唯一名字，而且它从不出现在题目里**。

### 在服务器上

什么都没有。服务是一个单一的程序，回应一个请求后就把它忘掉。它没有数据库，没有磁盘，也没有您数据的缓存。

您的 Google 登录信息也不会被存储：它经过加密，与您登录时所在的国家一起，放进服务交给您的聊天的令牌里，详见下文。密钥保存在 Google Secret Manager 中，从不离开服务器。

### 在日志中

服务记录的是计数，而不是内容：一道题是被接受还是被拒绝、被拒绝的原因、花了多长时间、需要几次尝试、聊天提交的题目中每一部分占了多少字节、是否触及了某项限制，以及使用的是哪个版本的指令。关于同一道题所涉及的各次调用的日志行，共用一个为这道题生成的随机代码；它把这些行联系在一起，却不透露任何关于孩子的信息。

为了在不知道任何一个孩子是谁的情况下，统计每天、每周和每月有多少孩子使用 MathTrail，关于发出一道题、一次作答和掌握一个专题的日志行合在一起带有：

- 孩子的**统计用名**：一个由服务用自己的密钥、根据档案的标识符和日历月份生成的代码。它在一个月内保持不变，到下个月就会不同；从它推算不出任何关于孩子的信息，无论是标识符、化名还是其他任何内容；
- 聊天（Claude、ChatGPT 或其他）、题目的语言、年级、档案创建的月份，以及已掌握的专题数量；
- 在关于发出一道题的日志行中：**国家**和美国的**州**（如果您在档案中提供了），以及**您登录时所在的国家**，各以一个简短代码表示；
- 对于一次作答：它的专题、水平和难度，是否答对，答错时掉进的陷阱，是否用了提示，是否是“不知道”，作答有多快（一分钟内、三分钟内或更久），服务对这道题预期的**答对概率**，由谁选的题（服务的规则、聊天或您），是否属于用来确定孩子起始水平的最初几次作答，以及在这几次之后，孩子的作答次数所在的区段，例如6～20次。

和关于您各次会话的每一行日志一样，这些日志行还带有一个代表您账号的不透明代码：它由服务用自己的密钥根据您的 Google 账号生成，既不是您的 Google ID，也不是您的电子邮件地址；在该密钥更换之后，您第一次登录时它就会改变。在两个月的日志行同时保存期间，正是这个代码可能把同一个孩子的两个统计用名联系起来。在这些日志行保存期间，它也使关于作答的日志行成为您孩子逐一作答的记录：只有对错，从不包括所选的字母。

这些日志行最多保存62天。此后保存的是总数，即有多少孩子、多少道题、在哪些国家：每天的总数；每周和每月的总数，每次只按一个维度细分，例如国家或年级；以及每个月的以下数据：错误答案掉进了哪些陷阱，按专题和年级统计；服务所选的题目实际答得如何、与其预期的答对概率相比怎样，按这一概率和孩子已作答的次数统计。总数中不含任何形式的标识符。一个总数统计的是一组孩子，而一组也可能只有一个孩子；小于十的总数从不公开展示。

日志中从不包含化名、题目文本、答案的字母、电子邮件地址、令牌、孩子的标识符，也不包含请求的来源地址。

另外，Google Cloud Run 会为运行在它上面的任何服务的每个请求保存一份标准记录：时间、来源地址、浏览器自报的身份、发出请求的页面、所请求的完整地址、状态码，以及响应的大小和耗时。登录过程中，所请求的地址里带有聊天和 Google 放进去的内容：Google 的一次性登录代码（只有本服务才能兑换）、Google Workspace 账号的域名，以及聊天建议用来登录的电子邮件地址（如果它提出了建议）。这份记录不含档案数据、题目文本或答案，保存30天。

### 您登录时所在的国家

您登录时，Google 会把您的浏览器送回 MathTrail；只在这一刻，服务会在 DB-IP 的免费 IP-to-Country 数据库中查找您浏览器的地址属于哪个国家。这个数据库是服务保存在自己服务器上的一个文件，因此不会向 DB-IP 或其他任何人发送任何内容。只保留国家的两字母代码，密封在您的聊天所持有的令牌中；地址本身既不存储，也不记录。不属于任何国家的地址（例如私有网络中的地址）查不出任何国家。您的聊天自己发出的请求来自它的服务器，而不是来自您，因此国家始终是您最近一次登录时的那个。

您可以让这个国家不计入统计：在档案表单中勾选“不统计我登录时所在的国家”，或者在聊天中提出。此后，服务写下的任何一行日志都不会带有它，直到您取消勾选。

IP 地理定位由 [DB-IP](https://db-ip.com) 提供，采用 [Creative Commons Attribution 4.0](https://creativecommons.org/licenses/by/4.0/) 许可协议。

## 这些信息各有什么用途

- **档案**：用来挑选每道题及其难度、显示进度，以及执行每天的上限。
- **登录和您账号的代码**：用来访问您的那一个文件而不涉及其他任何内容，以及执行每个账号的限制。
- **国家和州**：只用于统计每个国家有多少家庭。两者您都可以排除在外。
- **日志**：用于运行服务、查找故障，以及了解题目的实际表现。
- **总数**：用于了解 MathTrail 的使用情况，以及它的题目有多适合孩子。它们只以十名或更多孩子的总数形式展示，见于本网站的“研究”页面和资助申请中。

## 各自保存多久

- **档案文件**：保存到您删除为止。删除的文件会在云端硬盘的回收站里保留30天，除非您清空回收站。云端硬盘会在版本记录中把文件的早期版本保留一段时间；对于档案发生改动的每一天，MathTrail 会请云端硬盘永久保留当天的第一个版本，最多两百个。
- **您的聊天持有的令牌**：15分钟；它会续期，每次最多延续30天，从登录起最长90天。
- **登录用的两个 Cookie**：把一次登录串联起来的那个保存10分钟，记住您批准过哪些应用的那个保存180天。
- **服务的日志，以及 Cloud Run 的请求记录**：30天。
- **用来统计孩子的日志行副本**：62天。
- **跟踪记录**，即请求耗时的记录：30天。它们大约覆盖十分之一的请求，其中的地址、浏览器、路径和查询参数都已抹去。
- **服务运行的测量数据**，例如有多少次调用成功：24个月。其中不含任何关于孩子的内容。
- **总数**：保存多年。其中不含任何形式的标识符。
- **本网站的访问日志和您的对话**：保存多久，由 GitHub 和您的聊天服务提供商按各自的政策决定。

## Google 登录和云端硬盘

登录时只向 Google 申请一项权限：**`drive.file`**。这是范围很窄的云端硬盘权限：它**只允许访问本应用自己创建的文件**。您云端硬盘中的其他任何内容，包括您自己创建的文件，MathTrail 都无法查看、列出或打开。

为了知道是谁登录的，服务随后会询问 Google 是哪个 Google 账号授予了这项权限。Google 告诉它的是这个账号的标识符，而不是您的电子邮件地址；服务只保留它根据这个标识符生成的代码，也就是上文所述的那个代码。

有两个后果值得提前知道，因为它们看起来像故障，其实不是：

- **每次连接时，Google 都会请求您的许可**。服务自己不保存任何长期有效的 Google 凭据，因此每次连接都必须重新获取一个，Google 也就每次都会显示它的权限页面。
- **一个 Google 账号同时只允许大约一百个这样的授权**。大约连接一百次之后，最早的那个授权会停止生效，而且没有任何提醒。重新登录即可解决。

服务发给您的聊天的令牌有效期为15分钟，会自动续期，每次最多延续30天，从登录起最长90天。之后需要重新登录。

## 哪些内容会传到聊天模型

MathTrail 工具返回的所有内容都会被聊天模型读取，因此会和对话的其余部分一起到达您的聊天服务提供商。一节课下来，这几乎就是档案中的全部内容：

- **档案和进度**：化名、年级、兴趣爱好、排除在外的技能、您写的备注、课程语言、国家和州（如果您提供了）、为课程选定的专题、评分及其变化、已掌握的专题、最近的作答、反复出现的错误，以及档案文件在您云端硬盘中的位置和链接；
- **出题材料**：专题、难度、例题、要遵循的格式、年级、兴趣爱好，以及**您写下的关于孩子的自由备注**，模型正是靠这些备注把措辞调整到合适的水平；
- **作答结果**：是否答对、正确选项、答错时掉进的陷阱，以及解答。

写备注时请记住这一点：它们会和其他所有内容一起发送给聊天服务提供商。任何结果中都不含孩子的标识符，化名也从不会进入题目文本。

题目文本本身由模型写出，并经过 MathTrail 的检查再传回来。

## 您能看到什么，聊天会显示什么

聊天宿主会显示应用所发起调用的原始参数。模型提交一道写好的题时，这次提交的内容（**包括正确答案**）对任何查看聊天窗口中工具调用记录的人都是可见的。

MathTrail 不隐藏这一点，也无法隐藏。答案经过加密，因此无法从档案文件中取出，也无法被发出两次；但对于查看自己聊天中调用记录的成年人，它并没有被隐藏。如果您希望题目保持悬念，请不要当着孩子的面翻看调用记录。

## 广告、用户画像和模型训练

MathTrail 中没有广告。关于您孩子的任何信息都不会用于建立广告画像；任何数据都不会被出售，也不会提供给数据经纪商。MathTrail 不会用您孩子的数据训练任何模型。

聊天服务提供商如何处理对话，由其自己的政策规定，也就是已经适用于您在该聊天中发送的其他每条消息的同一份政策。

## Cookie

本网站不设置任何 Cookie，不运行任何分析工具，也不从其他域名加载任何内容。

服务只在登录期间设置两个 Cookie，两者都是严格必需的：一个把登录的开始和结束联系起来，另一个记住您已经批准过哪些应用，这样就不会再问您第二次。两者都不用于追踪。

## 取回和删除您的数据

所有内容都在您自己的云端硬盘里，因此一切都由您掌控：

- **导出**：在云端硬盘中打开 `MathTrail` 文件夹，下载 `mathtrail-profile.json`。这个文件就是整个档案。
- **删除**：删除这个文件。清空云端硬盘的回收站，即可彻底移除它。档案的任何部分都不会在别处留存。
- **取消授权**：前往您 Google 账号的“[关联的应用](https://myaccount.google.com/linkedapps)”页面，撤销 MathTrail 对您账号的访问权限。此后服务将无法访问任何内容。
- **移除应用**：在聊天应用自己的设置中断开与 MathTrail 的连接。

删除文件和撤销访问权限互不影响；两者都做，就什么都不会留下。

## 还有谁参与其中

- **Google**：登录和云端硬盘，您的文件就存放在那里（[Google 隐私权政策](https://policies.google.com/privacy)）。
- **Google Cloud**：服务运行在它的 Cloud Run 上，上文所述的总数保存在它的 BigQuery 中（[Google Cloud 隐私声明](https://cloud.google.com/terms/cloud-privacy-notice)）。
- **GitHub Pages**：本网站由它托管；GitHub 会为本网站记录自己的访问日志（[GitHub 隐私声明](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement)）。
- **您的聊天服务提供商**：Claude 的提供商是 Anthropic（[Anthropic 隐私政策](https://www.anthropic.com/legal/privacy)），ChatGPT 的是 OpenAI（[OpenAI 隐私政策](https://openai.com/policies/privacy-policy/)）。

运营 MathTrail 的人员可以在 Google Cloud 中查看服务的日志和总数，其中只有上文所述的内容，别无其他。除此之外，再没有其他人。
