# Russian (`ru`)

The Russian is written beside the English, so it needs no glossary. These notes hold the words parents type when they look for problems like the site's, which a title, a description and a topic's first line use as [the brief](README.md#search-words) says.

## Search words

Gathered on 2026-10-12 from Yandex's and Google's suggestions and the titles of the first results. The two engines agree on every strong phrase.

**Who searches, and how.** In Russia Yandex is 70 % of searches and Google 28 %; in Belarus and Kazakhstan Google leads, and the diaspora uses Google. Parents type one grade, «олимпиадные задачи 3 класс», «для 3 класса», or a pair, «5-6 класс», «3-4 класс»; a wider range finds nothing on either engine. Logic puzzles are also searched by age, «для детей 7-8 лет». `topics.grades`, «{range} класс», is the typed pair word for word. Both engines read «е» for «ё», so «четность» and «счет» find the site's «чётность» and «счёт».

**What parents type**, strongest first:

1. «олимпиадные задачи по математике N класс», far ahead of «олимпиадные задания» and «олимпиадная математика»;
2. «логические задачи», «задачи на логику», for children or a grade;
3. «нестандартные задачи по математике N класс»;
4. «задачи на смекалку N класс»;
5. «олимпиадная математика», for a grade, for children, online;
6. «задачи повышенной сложности N класс»;
7. «олимпиадные задачи для начальной школы».

**The head's title.**

- A topic's page: **«{topic}: олимпиадные задачи, {range} класс»**. «Задачи на {topic}» would not do: the topic's name would have to change its case, «на рыцарей и лжецов». The longest, «Отношения и деление на части: олимпиадные задачи, 5–6 класс», is 59 units. The other way, «{topic} — олимпиадные задачи, {range} класс», reaches 60.
- Any other page: **«{page} — MathTrail»**; the longest, «Приёмы решения олимпиадных задач по математике — MathTrail», is 58.

«Задачи на отношения» and «пропорции» go to the page of ratios, and «дроби» to the page of parts; each page also keeps its card's name, so «части» stands in both. The first line of ordering, enumeration, the pigeonhole principle and overlapping groups gives its searched name too.

**Descriptions** can carry «олимпиадные задачи по математике», «логические задачи», «нестандартные задачи», which the page «Зачем» uses itself, and «бесплатно», a fact. «С решениями» fits a topic's page and «Приёмы» only.

**Not to use.**

- The event, «олимпиада по математике N класс», and the names of contests and schools: ВсОШ, олимпиада Эйлера, ММО, Турнир городов, олимпиада Шарыгина, МатЧемп and «Олимпиада 2×2», «Отличник», «Блиц-олимпиада», «Систематика», «Малый мехмат МГУ».
- Textbooks and their authors, Петерсон, «Школа России», Левитас, and the state tests, ВПР, ОГЭ, ЕГЭ.
- What the site does not give: «карточки», «тренажёр», «скачать», «презентация».
