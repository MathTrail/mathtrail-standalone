\section{Related Work}
\label{sec:related}

\paragraph{Generating and checking problems.} Language models have written word problems for kindergarten to grade~\stat{literature}{mathwell_grade_max}, each answered by a program the model wrote and judged by teachers~\cite{christ2024mathwell}, problems for grades \stat{literature}{edumath_grade_min}--\stat{literature}{edumath_grade_max}~\cite{christ2026edumath}, and routine exercises for the elementary grades, where a model agreed poorly with people on whether a problem could be solved~\cite{ariyarathne2025elementary}. Among the works we read, none writes olympiad-style problems for primary school, and none admits a problem by running a program its author wrote against the problem's options. The nearest are GSM-Symbolic, which computes each key with a program people wrote~\cite{mirzadeh2024gsmsymbolic}; Beast Academy, olympiad-style problems for ages \stat{literature}{beastacademy_age_min}--\stat{literature}{beastacademy_age_max} written by people~\cite{beastacademy2026}; and MathForces, which generates olympiad quizzes with a model for an audience it does not state, with no check it describes~\cite{mathforces2026}. A model reviewing its own reasoning without outside feedback rarely finds its mistakes~\cite{huang2023large}; a program can compute the answer instead~\cite{chen2022program}, and a model can check its own answer with code it writes, reading the result itself~\cite{zhou2023solving}. Elsewhere, model agents judge the problems a model rewrote~\cite{ikram2026multiagent}; we take the program route without a second model: the service runs code the model wrote and compares the result with the model's own key.

\paragraph{Learner models and difficulty.} Our response model is the logistic model with the guessing floor of Birnbaum's three-parameter model~\cite{birnbaum1968some}, its slope fixed as in Rasch's, updated as the hierarchical Elo rating of adaptive practice: a general level corrected by a topic level, with a step that shrinks with the number of answers~\cite{pelanek2017elobased}. Math Garden estimates ability and item difficulty on the fly and aims at an expected success of \stat{literature}{klinkenberg_target_success}~\cite{klinkenberg2011computer}. Our tasks are never reused, so a task's difficulty cannot be learned from other children's answers: it is asked for, and the model's writing must deliver it. The Bayesian trackers that give the step a principled size, Glicko-2 and Urnings among them, have, as published, no guessing floor~\cite{glickman2022glicko2,bolsinova2022urnings}.

\paragraph{Tutors inside chat assistants.} Unguarded chat help can harm learning: high-school students who had practised with a plain GPT-4 chat did worse on a later exam than those who never had it~\cite{bastani2025generative}. Where tutoring with a model helped, correctness came from outside the model, such as instructors' solutions in the prompt~\cite{kestin2025ai}. We found no trial of a model that writes tasks for children of primary age. An open-source MCP tutor separates what the model writes from a rule-driven engine of progression, as we do, but describes no check of what the model writes~\cite{guiovanna2026tutor}.
