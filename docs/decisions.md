## Протокол и SDK

**R01. Go SDK — v1.8.0.** PRODUCT 7 называл v1.7.0; на 2026-09-16 актуальна v1.8.0 (14.09.2026) — патч-релиз без изменений протокола: набор поддерживаемых версий тот же, 2026-07-28 остаётся новейшей. Добавлены лимиты на размер SSE-события, тела запроса и глубину JSON, настройка `ServerOptions.SupportedProtocolVersions` и явный код `-32022` вместо голого 400. Спайк T03 собран и проверен на ней. — *Почему:* строго новее и полностью совместима, держаться прошлого патча незачем. — *Где живёт:* `go.mod` (T17), PRODUCT 7.

**R02. Сервер не сужает список версий протокола.** Работаем только по 2026-07-28 (О-20, О-28), но `SupportedProtocolVersions` оставляем в состоянии по умолчанию: SDK сам предпочитает новейшую версию при согласовании. — *Почему:* в строгом режиме Claude не добавляет коннектор. Перед основной сессией хост шлёт два коротких легаси-`initialize` с пустой версией, и отказ по версии ломает шаг «Connect» (status 400); в обычном режиме те же прогоны целиком идут по 2026-07-28 — ни один настоящий запрос не согласовал версию старее. — *Отвергнуто:* строгий режим «только 2026-07-28» на транспорте; запасной путь stateless 2025-11-25 (О-28). — *Где живёт:* T41; перепроверить в ChatGPT — T63.

## Вход и права

**R03. Регистрация клиентов — CIMD, DCR остаётся запасным.** Метаданные сервера авторизации объявляют `client_id_metadata_document_supported: true`, сервер сам забирает документ по HTTPS-`client_id`; `/register` (RFC 7591) поддерживается ради обратной совместимости. — *Почему:* с 2026-07-28 DCR формально устарел, и Claude вживую пришёл именно с CIMD (`client_id: https://claude.ai/oauth/mcp-oauth-client-metadata`), ни разу не откатившись на DCR; документация ChatGPT тоже рекомендует CIMD, но вживую он не проверен. — *Где живёт:* T07, T47–T49.

**R04. Нехватка прав у инструмента — HTTP 403 с заголовком `WWW-Authenticate`.** Поле `_meta["mcp/www_authenticate"]` в результате вызова добавляется дополнительно, ради ChatGPT, но единственным механизмом быть не может. — *Почему:* живой прогон T04: на 403 Claude сам сходил на `/authorize` за расширенным scope и сам повторил неудавшийся вызов, без участия человека; инструмент, отвечавший только через `_meta`, выглядел для него обычной ошибкой. — *Следствие:* step-up модель не видит — в её контексте один успешный вызов, поэтому её рассказ о состоянии авторизации ненадёжен, судить можно только по логу сервера (это же правило — для всех приёмочных прогонов). — *Где живёт:* T47–T49.

## Инструменты и окружение

**R05. Отдельного файла версий инструментов нет.** Точная версия закрепляется там, где инструмент ставится: `ARG` в `.devcontainer/Dockerfile`, литерал в `devcontainer.json` и `devcontainer-lock.json`, версия модуля в `go.mod`, точная версия плюс lock-файл в npm, SHA коммита в GitHub Actions. — *Почему:* один источник правды на инструмент; отдельный файл версий пришлось бы вручную держать в согласии с этими же местами, а сборка всё равно читает версии оттуда. — *Отвергнуто:* общий файл версий; проверка контрольных сумм сверх той, что уже делает `go install`. — *Где живёт:* CLAUDE.md («Exact versions only»), T01.

## Виджеты

**R06. Пакет `@modelcontextprotocol/ext-apps` версии 2.0.0; ориентир — библиотека, а не текст спецификации.** Там, где спецификация MCP Apps 2026-01-26 расходится с библиотекой — в `ui/message` и `ui/update-model-context` поле `content` у неё всегда массив блоков, а не одиночный объект, — пишем по библиотеке. — *Почему:* её код и есть реальный рантайм хостов; расхождение найдено в T03 при сборке виджета. — *Где живёт:* T42, `web/package.json`.

## Инструкции для модели

**R07. Тексты для модели не полагаются на точное имя инструмента.** Claude префиксует имена именем коннектора (`MathTrail:show_widget`). Инструкции описывают инструменты по назначению и по имени без префикса, не требуя дословного совпадения; в текстах для ребёнка и родителя имён инструментов нет вовсе. — *Почему:* префикс добавляет хост, и у каждого хоста он свой; инструкция, завязанная на точное имя, ломается при смене хоста. Найдено в живом прогоне T03. — *Где живёт:* T36; перепроверить в ChatGPT — T63.
