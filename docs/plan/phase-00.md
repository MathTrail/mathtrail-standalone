    - Node LTS — точная, для виджета;
    - `just`, `golangci-lint`, `mockery`, `cloudflared` — точные версии;
    - Claude Code — CLI и расширение VS Code одной версии, как в прототипе: том для `~/.claude`, `CLAUDE_CONFIG_DIR`, `DISABLE_AUTOUPDATER`.
  - Версии инструментов закреплены прямо там, где нужны, без отдельного файла версий и без проверки чек-сумм: `ARG` в `.devcontainer/Dockerfile`, те же значения литералом в `devcontainer.json`.
  - Расширения VS Code — точные версии: Go, Claude Code, YAML, justfile, Mermaid, GitLens, Docker.
  - `post-start.sh`: `git config core.hooksPath .githooks`, если папка есть.
  - `.gitattributes`: `*.sh text eol=lf`.
  - Минимальный `justfile` с рецептом `default` (`just --list`).
  - `CLAUDE.md`, раздел Environment, и `README.md`, раздел для разработчиков: как открыть проект в контейнере.
- **Как проверить:** «Reopen in Container» → внутри работают `go version`, `node --version`, `claude --version` и `docker run --rm hello-world`, версии совпадают с закреплёнными в Dockerfile и devcontainer.json. Пересборка контейнера без кеша даёт те же версии.
