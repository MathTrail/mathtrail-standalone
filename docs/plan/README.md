# Архив плана

Сюда из [RUN.md](../../RUN.md) уходит сделанное: по файлу на фазу, а сделанные задачи раздела «Доработки» — в свой файл. Всё перенесено дословно и, как RUN.md, на русском. Архив целиком не читается: из него берут задачу, на которую есть ссылка, по её номеру.

```
grep -nE -e '^### T75\.7[.–]' -e '^ *- \*\*T75\.7[.*]' RUN.md docs/plan/*.md
```

Точки в номере экранируются. Первый шаблон находит заголовок задачи, второй — её строку внутри общего заголовка вроде `### T75.6–T75.9.`. У группы, например T72 или T37, команда находит и все её части. Если не нашлось ничего, это общий номер задач с буквами: T29 — это T29a и T29b, и их ищут по началу номера, `^### T29`. Обёртка, которая ещё открыта, находится дважды: в RUN.md и в копии здесь.

Ссылки в задачах архива, как и в RUN.md, ведут от корня репозитория: отсюда они не открываются, и путь читается от корня. Какие фазы здесь лежат, перечислено в RUN.md, а когда и как фаза уходит сюда, сказано там же, в разделе «Как устроен план».
